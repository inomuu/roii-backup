## 4. สิ่งที่ตัดสินได้จากตลาดจริง

1. **อย่าหวังให้ "ของฟาร์มทุกด่าน" มีค่า** — Sigil / gem เกรดต่ำ / T3 gear / fodder จะชน $0.03 ทันที
   การเปิด trade ของพวกนี้ไม่ช่วยคนช้า (ข้อเสนอเดิม "fodder ดรอปทุกด่าน + trade ได้" **ตก** — มันจะเป็น Soulstone)
2. ของที่คนช้าขายได้ต้องเป็น **"tier ที่คนส่วนใหญ่กำลังใช้ตอนนี้ แต่ยังต้องฟาร์ม"** — ของเราคือ **T4-T5 gear + gem
   Rare/Legendary + off-hand T4-T5** ในช่วง stage 100-168 ที่ผู้เล่นทั่วไปอยู่ ซึ่งต้องการ 2 อย่างที่ตอนนี้ยังไม่มี:
   - **supply ไม่ล้น**: drop rate gear T4-5 ต่ำพอ (ตอนนี้ `slot_bp` 12-24 bp ต่อช่อง ≈ WoG-ish) + **ไม่มี** stackable
     gear — ชิ้นละ 1 listing (เรามี server-rolled star/lines = ชิ้นไม่เหมือนกันอยู่แล้ว ✓)
   - **demand ไม่หมด**: whale ที่ T6 ไม่ซื้อ T5 — demand ต้องมาจาก**คนกลางเกมด้วยกัน** (ผู้เล่นใหม่ไล่ตาม) และจาก
     **sink**: fusion 6→1 (T5 ×6 → T5 grade สูงขึ้น — fusion ขึ้น grade ไม่ขึ้น tier) และ disenchant → crest
     T5 คือ sink ที่ทำให้ whale **ยังซื้อ T5** — มีอยู่แล้วในระบบ (`fusion`, `crest::disenchant`)
3. **off-hand ขายได้เท่าช่องอื่น** (Tri-Color Ammo = off-hand Lv60 ของ gunner, T5 26¢ / T6 $5.33) — ตรงกับ
   Tome / Quiver / Hidden Knife / Shield T4-T5 ของเรา (0.0.446) พอดี. (แก้ 2026-09-21: อ่านครั้งแรกว่าเป็น
   consumable — ผิด.) Consumable ที่ craft-แล้ว-trade ยังเป็นช่องที่น่าทำ แต่ไม่มีตัวอย่างจากสองเกมนี้
4. เป้าตัวเลข: ของ "กลางเกม" ควรมี **listing หลักสิบ-ร้อย ราคา 10-50 เซนต์** — ถ้าเห็นหมื่นชิ้น = ดรอปเยอะไป
   ถ้าเห็นหลักหน่วย = ดรอปน้อยไป/ไม่มีคนถึง
