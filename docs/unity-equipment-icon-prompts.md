# Equipment painted icon prompts

Generated 2026-09-13 using the built-in `image_gen.imagegen` tool, one independent request per icon. These are original generated category assets for the Unity Equipment prototype, not a complete per-item art catalog. They share restrained hand-painted steel/brass/cloth art direction. No external reference bitmap or copied game art was used as image input.

All ten PNGs are original 1254 × 1254 RGBA output with actual transparent pixels and alpha range 0–255. Original pixels and alpha were preserved by byte-for-byte copy; no background removal, recolor, crop, or resampling was performed. Unity import/downsampling is owned by the presentation integration. Sword/Staff are the beginner weapon illustrations; the other assets are reusable category-level art. Validate subject, silhouette, alpha edges and readability in Unity at final slot size.
