# Character Brief - Wall Patrol Lightning Duo

## 1. คอนเซปต์ทีม

**ทีม:** หน่วยลาดตระเวนกำแพงเมือง

**โทนทีม:** ถังแตก งบน้อย อุปกรณ์เก่า แต่ทำงานจริง

**สมาชิกใน brief นี้:**

- นักธนูลม/สายฟ้า - Wind Striker SR
- Sentinel สายฟ้า - Wind Sentinel SR

ทั้งสองเป็นคู่หูประจำแนวกำแพงเมือง หนึ่งคนยืนหน้าเพื่อรับอันตราย อีกคนอยู่หลังเพื่อมองเห็นอันตรายก่อนมันจะมาถึง

ภาพรวมของคู่นี้ควร casual, น่าเอ็นดู และมีความเป็นเพื่อนร่วมงานที่อยู่ด้วยกันมานาน

## 2. Dynamic หลัก

| Sentinel | Archer |
|---|---|
| ขี้กลัว ขี้กังวล | ชิล ขี้เล่น ปากไว |
| ทำตามคู่มือ | ทำตามสัญชาตญาณ |
| ถือโล่ ยืนหน้า | ถือธนู ยืนหลัง |
| เช็กแผนหลายรอบ | เห็นช่องยิงตั้งแต่แรก |
| กลัวแต่ไม่ถอย | ทำเหมือนไม่กลัวเพื่อให้คู่หูใจเย็น |

หัวใจของ duo:

**คนหนึ่งกลัวแต่ยังยืนอยู่ข้างหน้า อีกคนเห็นอันตรายก่อนใครเลยต้องทำเหมือนทุกอย่างไม่เป็นไร**

## 3. Silhouette คู่กัน

Sentinel:

- ตัวเล็กกว่า
- โล่ใหญ่
- ท่ายืนเกร็ง
- ชุดยามเมืองที่ค่อนข้างเรียบร้อย
- สีหน้ากังวล

Archer:

- สูงกว่าเล็กน้อย
- ธนูยาว
- ท่ายืนสบาย ๆ
- ชุด scout หลวมและคล่องตัวกว่า
- สีหน้าครึ่งยิ้มครึ่งเบื่อ

เมื่ออยู่ด้วยกัน ควรเห็น contrast ทันที:

**โล่ใหญ่กับธนูยาว / คนตื่นกับคนชิล / แนวหน้ากับแนวหลัง**

## 4. สีและทีมเวิร์ก

ทั้งคู่ควรใช้ palette ที่อยู่ทีมเดียวกัน

**สีทีมหลัก:** เขียวหม่น / เทาอมเขียว / น้ำเงินหม่น

**สีรอง:** หนังสีน้ำตาล / เงินเก่า / ขาวหม่น

**สี accent:** เหลืองสายฟ้า / เขียวอ่อน

Sentinel ควรสว่างและน่าเอ็นดูกว่าเล็กน้อย

Archer ควรหม่นและชิลกว่าเล็กน้อย

อาจมี matching item เช่น:

- ผ้าพันคอทีมสีเดียวกัน
- เครื่องหมายหน่วยกำแพง
- ริบบิ้นหรือผ้าผูกอาวุธที่เป็นของคู่กัน
- สติกเกอร์เล็ก ๆ บนโล่ที่ Archer แปะให้

## 5. อุปกรณ์คู่

Sentinel:

- โล่ใหญ่ มีคริสตัลสายฟ้าฝังอยู่
- คู่มือทหารยาม
- whistle เรียกกำลังเสริม
- เครื่องรางเล็ก ๆ

Archer:

- ธนูเบา มีคริสตัลสายฟ้าขนาดเล็ก
- กล้องส่องทางไกลเก่า
- กระเป๋าลูกธนู
- ลูกอม/ขนม

อุปกรณ์ควรมีรอยซ่อม รอยปะ หรืออะไหล่ไม่เข้าชุด เพื่อสื่อว่าหน่วยนี้งบน้อย

## 6. Mood Shot สำหรับ Artist

ภาพที่ 1:

Sentinel ยืนหน้าโล่ใหญ่ สีหน้ากลัวแต่พยายามตั้ง guard ส่วน Archer ยืนพิงกำแพงด้านหลัง ยกธนูขึ้นแบบสบาย ๆ ดวงตามองเป้าหมายไกลออกไป

ภาพที่ 2:

Sentinel กำลัง panic เพราะเจอมอนสเตอร์นอกกำแพง Archer ยื่นลูกอมให้แบบไม่ทุกข์ร้อน พร้อมยิงธนูผ่านไหล่ Sentinel ไปโดนศัตรูด้านหลัง

ภาพที่ 3:

ทั้งคู่กำลังนั่งพักบนกำแพงเมืองหลังเลิกงาน Sentinel ตรวจ checklist ส่วน Archer นอนพิงกระเป๋าลูกธนูและบ่นว่าอยากกลับบ้าน

## 7. Gameplay Pair Fantasy

เมื่ออยู่ทีมเดียวกันควรรู้สึกว่า Sentinel เปิดพื้นที่ให้ Archer ยิง และ Archer คอยปกป้อง Sentinel จาก blind spot

ไอเดีย synergy:

- Sentinel ใช้ shield แล้ว Archer ได้โอกาสยิง counter
- Archer mark ศัตรูที่กำลังโจมตี Sentinel
- เมื่อ Sentinel HP ต่ำ Archer ยิง interrupt ศัตรูทันที
- เมื่อ Archer โดนเล็ง Sentinel เปิด barrier ให้

Sentinel เป็น **Wind Sentinel SR**

Archer เป็น **Wind Striker SR**

ทั้งคู่ใช้ธีมสายฟ้า แต่ยังนับเป็น Wind element เพื่อไม่เพิ่ม element ใหม่

## 9. ภาพจำของ Duo

ภาพหลัก:

คู่หูหน่วยกำแพงเมืองถังแตก คนหนึ่งเป็น Sentinel ตัวเล็กขี้กลัวถือโล่ใหญ่ อีกคนเป็นนักธนูรุ่นพี่สายชิลที่ดูขี้เกียจแต่ยิงไม่เคยพลาด

สิ่งที่ผู้เล่นควรจำได้:

**อ๋อ คู่หูกำแพงเมืองนี่เอง คนหนึ่งกลัวแต่ไม่ถอย อีกคนทำเหมือนไม่สนใจแต่คอยมองหลังให้ตลอด**
