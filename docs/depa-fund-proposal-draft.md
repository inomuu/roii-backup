## 1. ชื่อโครงการ
**Minimal Idle MMO (ชื่อทำงาน: taskbar-arpg)** — เกม Idle ARPG ที่สร้าง "สำรับปาร์ตี้
เป็นบิลด์" บนแกนจำลองเชิงกำหนด (deterministic simulation)

## 2. หลักการและเหตุผล / ที่มา
- ตลาดเกม **Idle/Ambient** (เปิดทิ้งไว้ เล่นเรื่อยๆ) กำลังโต แต่ส่วนใหญ่ "ตื้น" — กดสะสม
  ตัวเลข ไม่มีความลึกของการวางบิลด์แบบ ARPG จริง
- โปรเจกต์นี้นำเสน่ห์ของ **Ragnarok Online** (ความลึกของบิลด์ + ระบบตีบวก/ของหายากที่
  เสี่ยง + เศรษฐกิจของเล่นเทรดได้) มาอยู่ในรูปแบบ idle ที่เล่นเองอัตโนมัติ
- จุดต่างเชิงเทคนิค: แยก **แกนเกม (logic)** ออกจาก **การแสดงผล (render)** อย่างเด็ดขาด
  ทำให้ตรวจสอบความถูกต้องได้โดยไม่ต้องเปิดเกม, เล่นซ้ำผลลัพธ์ได้ตรงกันทุกเครื่อง
  (cross-platform replay) และ **กันการปลอมแปลงสถานะ** ได้ด้วยการ reconcile แบบ hash-chain

## 3. วัตถุประสงค์
1. พัฒนาเดโมเล่นได้จริงถึง **Base Level 70 + การเปลี่ยนอาชีพ 1 ขั้น** แล้วปล่อยสู่ตลาด
2. พิสูจน์ **นวัตกรรมสถาปัตยกรรม deterministic core** ที่เป็นฐานของระบบกันโกง/เศรษฐกิจ
3. วางรากฐานเศรษฐกิจของเล่น (ตลาดในเกม → ตลาดเทรดจริงบน Steam เป็นเลเยอร์เสริม)
4. สร้างผลงานเกมสัญชาติไทยที่ส่งออกได้ผ่าน Steam (ตลาดโลก)

## 4. กลุ่มเป้าหมาย
- ผู้เล่นเกม idle/ARPG ทั่วโลกบน PC (Steam) — เดโมเป็นภาษาอังกฤษเพื่อตลาดสากล
- ผู้เล่นสาย "เปิดทิ้งไว้ ฟาร์ม วางบิลด์" และสายชอบความลึกแบบ RO

## 5. นวัตกรรมและเทคโนโลยี (จุดขายหลักต่อ depa)
- **Deterministic integer-only simulation core (Rust):** คณิตศาสตร์จำนวนเต็มล้วน ไม่มี
  ทศนิยม/เวลานาฬิกา/ลำดับสุ่มจากแฮช → ผลลัพธ์ reproducible 100% ทุกแพลตฟอร์ม
- **Hard boundary สถาปัตยกรรม:** sim-core (ตรรกะทั้งหมด) ↔ Godot (ตัวแสดงผลอ่านอย่างเดียว)
  เชื่อมผ่าน JSON อย่างเดียว — ลดบั๊ก ทดสอบอัตโนมัติได้ครบ (unit + golden state-hash + headless balance runner)
- **Anti-forgery by design:** เซฟ = (seed + สถานะเริ่มต้น + ลำดับ input) เล่นซ้ำได้ตรงบิต →
  เซิร์ฟเวอร์ตรวจ "ผลลัพธ์" ไม่ใช่สแกนโปรเซสเครื่องผู้เล่น (ไม่มี false-ban)
- **ผลพลอยได้:** สถาปัตยกรรมนี้ทำให้พัฒนาด้วย AI-assisted (vibe coding) ได้รวดเร็วและ
  ปลอดภัย เพราะพิสูจน์ความถูกต้องได้ก่อนรันเกมจริง — ลดต้นทุน/เวลาในการพัฒนา

## 6. จุดเด่น / ความแตกต่างจากคู่แข่ง
- **เสาหลัก: "สำรับปาร์ตี้ = บิลด์"** — วางบิลด์ระดับทีม 10 ตัว (ซ้ำคลาสได้) ไม่ใช่แค่ตัวเดียว
  เกม idle แทบไม่มีความลึกระดับนี้; ทีมล้วน (5 นักธนู / 5 เมจ / 5 สังหาร) ต้องเล่นได้และต่างกัน
- **ความลึกแบบ ARPG จริง:** สกิลทรี, ระบบธาตุ 9 ธาตุ, ระบบตีบวก (refine) ที่เสี่ยง,
  ของหายากเทรดได้ (เสน่ห์การ์ด RO)
- **เศรษฐกิจที่ออกแบบให้ยั่งยืน:** Gil หายาก + sink หลายชั้น (recruit/refine/respec/ร้านค้า)
  ปรับสมดุลด้วย headless simulation runner (จูนโดยไม่ต้องเปิดเกม)
- **คู่แข่งตรงเลน:** Tap Tap Loot (ทีม Bongo Cat) — จุดต่างของเราคือความลึก RO + เศรษฐกิจของเล่น
