## 1. ข้อมูลตั้งต้น

| | |
|---|---|
| เพดานเงินตัวเอง | **฿300,000** (ยอมเสียได้มากที่สุดก่อนหยุด) |
| ทุน depa | **฿200,000 — ยังไม่แน่ ผลออก ~กลาง ก.ย.** และ **ผูกปลายทาง ใช้ได้เฉพาะที่ยื่นไว้** |
| **กรณีฐาน (ไม่ได้ทุน)** | **฿300,000** ← วางแผนจากตัวเลขนี้ |
| **กรณีดี (ได้ทุน)** | **฿500,000** |
| วันเปิดตัว | สิ้นปี 2026 → เหลือ **~4.5 เดือน** |
| ขอบเขต | บทนำ + บทแรก + **ตัวละคร 15 ตัว** |
| อัตราแลกเปลี่ยนที่ใช้ | ฿34 / $1 |
| ⬜ ค่าครองชีพ/เดือน | **ยังไม่ระบุ** — ตัวแปรที่กระทบมากที่สุดรองจากอาร์ต |
| ⬜ งบการตลาด | **ยังไม่ระบุ** — ทุกเอกสารก่อนหน้าตั้งไว้เป็นศูนย์ |

**ข้อจำกัดของทุน:** ทุนจ่ายอาร์ต/เสียง/เครื่องมือ/Steam ได้ แต่จ่ายการตลาดกับค่าครองชีพไม่ได้
→ **฿300K ของคุณต้องแบกการตลาด + ค่าครองชีพ ทั้งหมด** บวกส่วนอาร์ตที่เกินจากทุน

**และผลทุนออกกลาง ก.ย. = เหลือเวลาถึงสิ้นปีแค่ ~3.5 เดือน** สั่งงานอาร์ตก้อนใหญ่หลังจากนั้น
แทบไม่ทัน → **ถ้าจะรอทุนก่อนค่อยสั่ง ต้องยอมรับว่าวันเปิดตัวเลื่อน**

## 3. งบพอกับ roster ขนาดไหน

ใช้ SR ที่ค่ากลาง $550 ≈ ฿18,700 · SSR ≈ ฿68,000

**ค่าคงที่ที่ต้องจ่ายทุกกรณี** — เสียง ฿20K + เครื่องมือ ฿20K + Steam ฿3.4K + เซิร์ฟเวอร์ ~฿9K
= **~฿52,400** (ยังไม่รวมอาร์ตของ "บทนำ + บทแรก" ซึ่งยังไม่ได้สโคป)
**ค่าครองชีพสมมติ ฿25,000/เดือน × 4.5 เดือน = ฿112,500** ⬜ ตัวเลขนี้ต้องยืนยัน

### กรณีฐาน — ไม่ได้ทุน (฿300,000)

```
฿300,000  ทุนตั้งต้น
−฿52,400  ค่าคงที่
−฿112,500 ค่าครองชีพ 4.5 เดือน
= ฿135,100 เหลือให้ อาร์ต + การตลาด ทั้งหมด
```

| ทางเลือก | อาร์ต | เหลือให้การตลาด |
|---|---|---|
| SR 7 ตัว | ~฿131,000 | **~฿4,000** — แทบไม่มี |
| **SR 5 ตัว** | ~฿93,500 | **~฿41,600** |
| SR 4 ตัว | ~฿74,800 | ~฿60,300 |
| SSR แม้แต่ตัวเดียว | ฿68,000 | ตัดตัวเลือกอื่นทิ้งเกือบหมด |

> **ตัวละคร 15 ตัวเป็นไปไม่ได้ในกรณีฐาน** — SR ล้วน 15 ตัวคือ ฿280K ซึ่งมากกว่าเงินที่เหลือ
> หลังหักค่าคงที่และค่าครองชีพถึงสองเท่า

### กรณีดี — ได้ทุน (฿500,000)

```
฿500,000 − ฿52,400 − ฿112,500 = ฿335,100 เหลือให้ อาร์ต + การตลาด
```

| ทางเลือก | อาร์ต | เหลือให้การตลาด |
|---|---|---|
| **SR 15 ตัว** | ~฿280,000 | ~฿55,100 |
| SSR 1 + SR 12 | ~฿292,400 | ~฿42,700 |
| SSR 3 + SR 12 | ~฿428,000 | **ติดลบ** |

> **แม้ได้ทุน 15 ตัวก็ทำได้เฉพาะ SR ล้วน และเหลือค่าการตลาดราว ฿55K เท่านั้น**
> SSR ตั้งแต่ 2 ตัวขึ้นไปทำให้แผนพัง

### ข้อสรุปของหัวข้อนี้

**ตัวเลขชี้ไปที่ roster 5 ตัวที่สเปกไว้แล้ว** (Seraphine / Lucielle / Skadi / Elfie / Noire)
SR ล้วน — เป็นทางเดียวที่อยู่รอดได้ทั้งกรณีได้ทุนและไม่ได้ทุน และยังเหลือเงินทำการตลาด
ส่วน 15 ตัวคือเป้าหมาย **ปีแรก** ไม่ใช่เป้าหมาย **วันเปิด**

## 4. ข้อจำกัดที่เงินแก้ไม่ได้ — ตารางเวลา

15 ตัว ÷ 4.5 เดือน = **~3.3 ตัว/เดือน**
ศิลปิน key art หนึ่งคนทำได้ราว **1–2 ตัว/เดือน** → ต้องมี **2–3 คนวาดขนานกัน**

เงินซื้อกำลังการผลิตขนานได้ แต่ซื้อสิ่งเหล่านี้ไม่ได้: การหาศิลปินที่ว่างพร้อมกัน 3 คน ·
การคุมให้ลายเส้นและการลงสีตรงกันทั้ง roster (`exemplar-roster.md` ย้ำว่า "สำคัญมาก") ·
เวลาของคุณเองในการบรีฟและตรวจงาน

**ฝั่งพิกเซลเป็นงานคนละก้อน** — `art-scope.md` สโคปไว้ที่ 15 ตัวผู้เล่น + 23 มอนสเตอร์
= 200 อนิเมชัน ~1,190 เฟรม

> ⚠️ **ความเสี่ยงหลักของแผนนี้คือตารางเวลา ไม่ใช่เงิน** ถ้าจะพลาด จะพลาดเพราะอาร์ตไม่เสร็จทัน

## 5. จุดคุ้มทุน — ต้องมีคนจ่ายเงินกี่คน

ARPPU จาก `depa-financial-projection.html` = ฿400–500/ปี · Steam หัก 30%
→ **สุทธิต่อผู้จ่ายหนึ่งคน ≈ ฿280–350/ปี**

| เป้าที่ต้องคืน | ผู้จ่ายที่ต้องมี (สุทธิ ฿300/คน) | ผู้เล่นทั้งหมด @ conversion 2% |
|---|---|---|
| **เงินคุณ ฿300K** (คืนทุนส่วนตัว) | ~1,000 คน | **~50,000 คน** |
| ทุนรวม ฿500K (กรณีได้ทุน) | ~1,670 คน | **~83,000 คน** |

**เทียบของจริงในหมวดเดียวกัน** (`competitive-landscape-idle-steam.md`)
- Desktop Raid — พรีเมียม $8.99, ~17,700 ก็อปปี้ → F2P ที่แย่กว่านี้ก็ยังได้ผู้เล่นมากกว่า
- TBH: Task Bar Hero — F2P, พีค 526,000 CCU

**~117,000 ผู้เล่นสำหรับเกม idle F2P บน Steam อยู่ระหว่างสองตัวนี้ — ทำได้จริง แต่ไม่ใช่ของแถม**
ตัวแปรชี้ขาดคือการมองเห็น ซึ่งคือช่องงบที่ยังว่างอยู่พอดี

## 6. คันโยก เรียงตามผลต่อความเสี่ยง

1. **ลดจำนวนตัวเปิดตัว 15 → 5–6** — roster ที่สเปกครบแล้วมี 5 ตัว (Seraphine / Lucielle / Skadi /
   Elfie / Noire) ปล่อยเพิ่มเดือนละตัวหลังเปิด ซึ่งเป็นจังหวะ live-ops มาตรฐานของเกมกาชาอยู่แล้ว
   **แก้ทั้งเงินและเวลาพร้อมกัน โดยไม่ต้องเลื่อนวันเปิด** — คันโยกที่ดีที่สุดในลิสต์
2. **เปิดด้วย SR ล้วน แล้วเติม SSR ทีหลัง** — SSR ตัวแรกกลายเป็นอีเวนต์หลังเปิดได้
3. **กันงบการตลาดก่อน ไม่ใช่เอาเศษที่เหลือ** — บทเรียนจาก Desktop Raid คือหมวดนี้ขายด้วย
   การมองเห็น ไม่ได้ขายด้วยคุณภาพ
4. **เลื่อนวันเปิด** — แต่คู่แข่งกำลังลงน้ำเดือนนี้ ([[My Party Is Grinding]] ส.ค. 2026)
5. **ขยับเพดาน** — เจ้าของโครงการตัดสิน ไม่เสนอ

## 7. ต้องเคาะก่อนลงดีเทลต่อ

- ⬜ **ค่าครองชีพ/เดือน** → กำหนดว่าทรง B หรือ C อยู่ในวิสัย
- ⬜ **งบการตลาดขั้นต่ำ** → ตอนนี้เป็นศูนย์ในทุกเอกสาร ทั้งที่เป็นตัวแปรชี้ขาดของจุดคุ้มทุน
- ⬜ **"บทนำ + บทแรก" ต้องใช้อาร์ตอะไรบ้าง** → ยังไม่ได้สโคป และเป็นค่าใช้จ่ายนอกเหนือจาก 15 ตัว
- ⬜ **15 ตัวคือจำนวนที่ต้องมีตอนเปิด หรือรวมที่ทยอยปล่อยในปีแรก** → ถ้าอย่างหลัง ปัญหาหายไปครึ่งหนึ่ง
