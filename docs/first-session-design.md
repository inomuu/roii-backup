## 3. แก้ที่ sim/catalog (วัดได้)

1. `boss_threshold` ไต่: ด่าน 1 = 8, +1 ต่อด่านถึง 30 ที่ด่าน 23 (ห้อง 2/3 +1/+2 เท่าเดิม) — ด่าน 1 จบใน 2-3 นาที แทน 24
2. wipe เดี่ยวด่าน 1: J ที่ด่าน 1-12 ต่ำกว่า 6% (เช่น 3% → 6% ที่ด่าน 12) — ผู้เล่นใหม่ไม่ควรตายใน 10 นาทีแรก
3. slot 2 **ฟรี** เมื่อผ่านด่าน 1 (`party.slot_gil[0] = 0` + เงื่อนไข "ผ่านด่าน 1") — ตัวที่ 2 มาพร้อม tutorial pull
4. gem `field_bp_by_stage` แถวแรกเริ่มด่าน 8 ไม่ใช่ 1

## 4. ที่ต้องเคาะ

- ตั๋ว 10-pull ตอนผ่านด่าน 1 (server) — ยืนยันว่าอยากให้เร็วขนาดนั้น
- UI gate ตามด่าน: ทำใน Unity (อ่าน `band_reached`) หรือให้ host ส่ง `unlocks` list
- บอส region (ด่าน 12/24/…) ควรมี "first clear reward" ไหม — ตอนนี้บอส region = แค่ห้อง 3 ของด่านสุดท้าย
