# Equipment white slot symbol prompts

Generated 2026-09-13 with the built-in `image_gen.imagegen` tool, one independent request per symbol. User clarified that the requested art is white slot symbols, not colored equipment illustrations. The earlier GearPainted iteration is retained separately and is not the intended slot-symbol set.

All ten original outputs were copied byte-for-byte into `unity/ROI/Assets/Resources/ExemplarUI/GearSymbols/`. They are 1254 × 1254 RGBA PNGs with actual alpha0–255. No external bitmap reference was supplied in the initial generation. No crop, threshold, recolor, or other image processing was applied.

Quality limitation: symbols have broad readable ivory silhouettes, but the generator left irregular ivory residue in some negative-space cutouts and around edges. Review at actual slot size before acceptance. Do not describe these originals as perfectly clean masks. The root UI integration owns final-size visual review.

## Integration review

The original set was reviewed in Unity at the actual 97-pixel square slot size and accepted
for this prototype. All ten symbols use a 512-pixel import limit, uncompressed color/alpha,
mipmaps and trilinear filtering; original files are preserved. Weapon and inspector icons
resolve through the same native category mapping. The current in-game capture is
[Equipment white symbols](previews/unity-exemplar-equipment-white-symbols.png).
The unused colored iteration is archived outside Unity at
`docs/design-checkpoints/gear-painted-unused/`.
